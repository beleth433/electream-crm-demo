# Courier EBike CRM — Система управления прокатом и ТО электровелосипедов для курьеров

Production-ready полнофункциональная CRM-система для коммерческого сервиса проката и сервисного обслуживания парка электровелосипедов (Minako Monster, Wenbox U3 Pro и др.), используемых курьерами служб доставки (**Яндекс Еда, Купер, Самокат**).

---

## 1. Ключевые архитектурные модули и бизнес-логика

- **Учет оборудования по номерам**: жесткий контроль по инвентарным номерам (`EV-001`), номерам рам (`FRM-...`) и номерам мотор-колес (`MTR-...`).
- **Стейт-машина техники (`Bike`)**: `AVAILABLE` ➔ `RENTED` ➔ `IN_MAINTENANCE` ➔ `FOR_SALE` ➔ `DECOMMISSIONED`.
- **Стейт-машина аренды (`Rental`)**: `DRAFT`, `RESERVED`, `ACTIVE`, `OVERDUE`, `CLOSED`, `PROBLEM`, `BOUGHT_OUT`.
- **Склад экипировки (`Outfit`)**: шлемы, закаленные замки 10мм, курьерские термосумки, сменные Li-Ion АКБ 60V 21Ah, быстрые ЗУ 5A, влагозащитные держатели телефонов, зимние муфты на руль. Статусы: `IN_STOCK`, `ISSUED`, `DAMAGED`, `LOST`.
- **Мастерская СТО (`RepairOrder`)**: статусы заказ-нарядов (`DIAGNOSTICS`, `WAITING_PARTS`, `IN_PROGRESS`, `COMPLETED`), транзакционное списание запчастей со склада при завершении, четкое разделение вины:
  - `COMPANY_EXPENSE`: плановое ТО, естественный износ колодок/цепи — за счет сервиса;
  - `CLIENT_FAULT`: повреждения при ДТП, падениях, залитии — счет курьеру или удержание из депозита.
- **Онбординг курьеров (`Client`)**: проверка паспорта РФ или комплекта документов СНГ (миграционная карта, патент/ЕАЭС), фиксация сервиса доставки, статусы `NORMAL`, `VIP`, `PROBLEM`, `BLACKLIST` (с блокировкой выдачи).
- **Печатный Акт приема-передачи**: официальный двусторонний акт с реквизитами сторон, серийными номерами оборудования, описью экипировки, регламентом эксплуатации и подписями.
- **Финансовый контур и KPI**: расчет выручки, себестоимости списанных деталей, фиксированных расходов точки, чистой маржи и коэффициента утилизации парка (Fleet Utilization %).
- **База знаний и FAQ**: статьи в Markdown по регламентам выдачи, зимней эксплуатации аккумуляторов 60V, скриптам общения при просрочке.
- **Отзывы курьеров**: система сбора оценок и комментариев по моделям байков.

## 2. Технологический стек

- **Frontend**: React 18+, Vite, TypeScript, Tailwind CSS, Lucide React, TanStack Query v5, React Hook Form, Zod, Sonner (Toasts), Dark/Light Theme.
- **Backend**: Node.js 22, TypeScript, Express, Prisma ORM, Multer (загрузка фото документов), Zod DTO валидация, архитектура Controller-Service-Repository.
- **База данных**: PostgreSQL 16 (с официальной схемой `prisma/schema.prisma` и скриптом `prisma/seed.ts`), а также встроенный отказоустойчивый Data Access Layer для мгновенного локального запуска.

## 3. Быстрый запуск

### Вариант 1: Запуск в режиме разработки (1 команда)
```bash
# Перейдите в каталог проекта:
cd courier-ebike-crm

# Запуск бэкенда (порт 4000) и фронтенда (порт 3000) одновременно:
npm run dev
```

Откройте браузер по адресу: **http://localhost:3000**  
API бэкенда доступно по адресу: **http://localhost:4000/api**  
Health-check: **http://localhost:4000/health**

---

### Вариант 2: Запуск с внешним PostgreSQL через Docker
```bash
# Запустить PostgreSQL 16 в фоне:
docker compose up -d

# Накатить схему базы данных и наполнить реалистичными данными:
cd server
npm run prisma:push
npm run prisma:seed
```
