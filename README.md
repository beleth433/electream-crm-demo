# ELECTREAM PRO SAMOKAT — Комплексная CRM-система для парков электровелосипедов

Production-ready полнофункциональная CRM-система корпоративного уровня для управления сервисом аренды, выкупа, розничных продаж и сервисного обслуживания парка электровелосипедов (Minako Monster, Wenbox U3 Pro и др.), используемых курьерами служб доставки (**Яндекс Еда, Купер, Самокат**) и розничными клиентами.

---

## 🚀 Ключевые возможности и 15 модулей системы

1. **Главный дашборд и аналитика (`Dashboard`)**:
   - Интерактивные графики выручки и прибыли (Recharts): динамика по дням, структура доходов (аренда, выкуп, розница магазина, платный ремонт).
   - Ключевые KPI парка: утилизация флота (Fleet Utilization %), текущая просрочка, открытые ремонты, остатки запчастей.
   - Встроенный командный чат базы с индикацией присутствия сотрудников (Presence).

2. **Аренда и долгосрочный выкуп (`Rentals`)**:
   - Двухрежимный мастер оформления: **Стандартная аренда** и **Аренда с выкупом (Rent-to-own)**.
   - Расчет графика платежей, себестоимости, первого взноса и остатка выкупа.
   - Подключение дополнительных аккумуляторов и экипировки при выдаче.
   - Печать официального двустороннего Договора и Акта приема-передачи с серийными номерами и описью экипировки.

3. **Магазин и оформление продаж (`Shop`)**:
   - Розничная продажа техники, АКБ, запчастей и аксессуаров.
   - Автоматическое списание проданных позиций со склада.
   - Модальное окно чека для термопринтера (80 мм) с реквизитами и разбивкой позиций.

4. **Парк техники (`Bikes`)**:
   - Учет по инвентарным номерам (`EV-001`), номерам рам (`FRM-...`) и мотор-колес (`MTR-...`).
   - Четкие русскоязычные статусы техники: *Свободен*, *В аренде*, *На ТО / В ремонте*, *На продаже*, *Списан*, *Выкуплен*.
   - Разделение напряжения (48V / 60V) и емкости (Ah), история перемещений и пробега.

5. **Аккумуляторы и АКБ (`Batteries`)**:
   - Учет химии ячеек (Li-ion, LiFePO4), циклов заряда/разряда, здоровья батареи (SOH %).
   - Статусы: *Свободен на базе*, *Установлен в байк*, *Выдан курьеру как доп. АКБ*, *На диагностике BMS*.
   - Визуальное модальное окно быстрой замены аккумулятора (Swap Battery) в 1 клик.

6. **Склад экипировки (`Outfits`)**:
   - Учет шлемов, закаленных замков 10 мм, курьерских сумок, зарядных устройств, держателей телефонов и зимних муфт.
   - Контроль залоговых депозитов, выдача и возврат при закрытии аренды.

7. **База курьеров и клиентов (`Clients`)**:
   - Учет паспорта РФ или пакета документов СНГ (миграционная карта, патент/ЕАЭС).
   - Модальное окно Phone QR: сканирование для быстрого звонка или перехода в мессенджер со смартфона.
   - Фиксация служб доставки (*Яндекс Еда*, *Купер*, *Самокат*, *Маркет Деливери*).
   - Карточка профиля клиента с историей розничных покупок и рангом программы лояльности.

8. **Сотрудники и RBAC доступ (`Employees`)**:
   - Разграничение ролей: *Владелец / SuperAdmin*, *Менеджер парка*, *Мастер СТО*.
   - Детальная матрица прав (просмотр, редактирование, удаление, просмотр прибыли P&L).
   - Учет условий оплаты (оклад, ставка за смену, сдельная оплата) и фиксация выплат зарплат.

9. **Мастерская СТО (`Repairs`)**:
   - Заказ-наряды для парковых электровелосипедов и **сторонней техники клиентов СТО**.
   - Статусы: *Диагностика*, *Ожидание запчастей*, *В работе*, *Готов к выдаче*.
   - Разделение ответственности: *Расходы сервиса (плановое ТО)* vs *Вина клиента (ДТП / поломка)*.
   - Автоматическое списание израсходованных запчастей со склада.

10. **Склад запчастей и Заявки на закупку (`Inventory`)**:
    - Двухрежимная панель: **В наличии на складе** + **Заявки на закупку (Мастер)**.
    - Автопарсинг ссылок на маркетплейс (Ozon) с извлечением названия и цены.
    - Приоритеты заявок, статусы согласования (*Запрошено*, *Заказано*, *Поступило на базу*).

11. **Касса и финансы (`Finance`)**:
    - Модуль импорта банковских выписок (1C / Excel).
    - Журнал кассовых операций с возможностью ручного добавления, редактирования и удаления.
    - Настройка реквизитов организации (СБП, счет, банк) и ежемесячных постоянных расходов.
    - Детализация выручки: аренда, выкуп, магазин, СТО.

12. **Система лояльности (`Loyalty`)**:
    - Автоматическая градация: *Бронза*, *Серебро*, *Золото*, *Платина*.
    - Настраиваемые пороги дней аренды / суммы трат и скидки на услуги и запчасти.

13. **База знаний и регламентов (`Info`)**:
    - Инструкции по регламентам выдачи техники, зимней эксплуатации АКБ, скриптам общения.

14. **Централизованный аудит (`History`)**:
    - Единый журнал всех ключевых действий сотрудников по всей CRM-системе.

15. **Документы (`Documents`)**:
    - Общий реестр договоров, актов, товарных чеков и заказ-нарядов СТО с поиском, фильтрами и переходом к операции.
    - Сохранённые данные на момент оформления, просмотр и печать/PDF. Старые операции восстанавливаются с явной пометкой; доступ наследуется от исходных разделов.

## 🛠 Технологический стек

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide React, TanStack Query v5, Recharts, XLSX (парсер выписок), QRCode.
- **Backend**: Node.js 22, Express, TypeScript, Zod DTO валидация, Multer, PostgreSQL / Supabase адаптер.
- **Аутентификация**: Trusted Device Gate с сохранением сессии и ролевой политикой доступа.

## 💻 Быстрый запуск

### 1. Установка зависимостей
```bash
# Установка зависимостей клиента и сервера:
npm run install:all
```

### 2. Запуск в режиме разработки
```bash
# Одновременный запуск фронтенда (порт 3000) и бэкенда (порт 4000):
npm run dev
```

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:4000/api
- **Health-check**: http://localhost:4000/health

### 3. Сборка для Production
```bash
npm run build --prefix server
npm run build --prefix client
```

### Локальный помощник для облачной CRM (пилот)

Команды вводятся или диктуются существующим приложением транскрибации в окно «Помощник» в шапке CRM. Предложения готовит локальная Ollama на подключённом компьютере, изменения сохраняются только после подтверждения в CRM. Поддерживаются клиенты и добавление велосипедов/АКБ по существующим моделям, с задачами по недостающим данным. Платный API не используется.

Запуск локальной программы: `npm run assistant:local`, затем http://127.0.0.1:47831 . Подключение — одноразовым кодом из обновлённой CRM. Для другого компьютера нужны Node.js LTS и Ollama; исходники всей CRM не требуются. [Установка, переносимая ZIP-сборка и ограничения](local-assistant/README.md).
