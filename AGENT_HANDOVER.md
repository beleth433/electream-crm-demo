## 1. О проекте (Что это за система)

**Courier EBike CRM** — это узкоспециализированная, высокосвязная ERP/CRM-система для коммерческого проката и сервисного обслуживания парка электровелосипедов (Minako Monster, Wenbox U3 Pro и др.) и аккумуляторов, используемых курьерами ключевых служб доставки (**Яндекс Еда, Купер, Самокат, Достависта**).

### Основная ценность системы:
- **Управление парком «в железе»**: Поштучный учет техники по инвентарным номерам (`ЭВ-001`), номерам рам (`FRM-...`) и мотор-колес (`MTR-...`).
- **Два режима аренды**: 
  1. *Классическая посуточная/недельная аренда* с залогом и возвратом;
  2. *Аренда с правом выкупа (Rent-to-Own)* с динамическим расчетом графиков платежей, фиксацией остатка долга и автоматическим переходом права собственности курьеру.
- **Полноценная мастерская (СТО)**: Обслуживание как собственного парка компании (`BIKE`, `BATTERY`), так и прием **сторонней техники клиентов** (`EXTERNAL_DEVICE`).
- **Склад и розничный магазин**: Автоматическое списание запчастей при ремонтах, кассовые розничные чеки, учет экипировки (шлемы, замки, термосумки, зарядные устройства, муфты).
- **Финансы и кадры**: Учет зарплат (оклады, за смену, сдельная за ремонты), фискальные чеки, расчет P&L, выручки и коэффициента утилизации парка (Fleet Utilization %).
- **Симулятор входящего потока курьеров**: Встроенный движок со сжатием времени ($1 \text{ день} = 15 \text{ минут}$), позволяющий проверять CRM в реальном времени.

### Стек технологий:
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React (иконки), TanStack Query v5, Zod, Sonner (всплывающие тосты), локальный шрифт **Rubik**.
- **Backend**: Node.js 22, Express, TypeScript, Zod (строгая валидация входящих DTO), Multer (загрузка фото документов курьеров).
- **Хранение данных (Двойной движок)**:
  1. **Встроенный автономный JSON DAL** (`server/data/crm_db.json` через `server/src/repositories/db.ts`) — позволяет мгновенно работать «из коробки» без внешних баз, сохраняя все сущности на диск при каждом изменении.
  2. **Prisma ORM** (`prisma/schema.prisma`) — production-ready схема для PostgreSQL 16.
