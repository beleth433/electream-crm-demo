# Сравнение локальных моделей — 2026-10-25

Проверки выполнены на компьютере пользователя: 16 ГБ ОЗУ, AMD Radeon RX 6600 с 8 ГБ видеопамяти. Ollama подтвердила полное размещение 7B на GPU, около 5,1 ГБ при контексте 8192. Платные API не использовались, рабочие данные CRM не изменялись.

Сравнивались установленная `qwen2.5:3b` и скачанная `qwen2.5:7b-instruct-q4_K_M` (7,6B, Q4_K_M, около 4,7 ГБ на диске). Каждая выполнила `smoke.mjs` (4 команды) и `regression-smoke.mjs` (6 команд) с одинаковыми настройками интеграции. Наборы используют синтетические записи и независимую проверку обязательных фактов.

| Сценарий | 3B, сек | 7B, сек | Проверка |
|---|---:|---:|---|
| Пакет: 3 велосипеда и 4 АКБ | 7,53 | 26,22 | Обе прошли |
| Новый курьер без паспорта и прописки | 1,83 | 10,18 | Обе прошли |
| Обновление прописки | 0,94 | 7,57 | Обе прошли |
| Клиент без телефона | 0,65 | 4,75 | Обе прошли |
| Три клиента без телефонов | 1,48 | 11,41 | Обе прошли |
| Три клиента с телефонами по порядку | 2,01 | 18,71 | Обе прошли |
| Неполный телефон второго клиента | 1,96 | 19,07 | Обе прошли |
| Неоднозначная стоимость 60 тысяч | 1,05 | 8,48 | Обе прошли |
| Закупочная цена 60 тысяч за единицу | 0,69 | 8,10 | Обе прошли |
| Запрошенной модели нет в каталоге | 0,82 | 8,09 | Обе прошли |

Медиана: 3B — 1,26 сек; 7B — 9,33 сек. Первый запрос 7B занял 26,22 сек и включает загрузку модели. Это локальные замеры при текущей нагрузке компьютера, а не гарантия задержки.

Обе модели прошли 10/10 сценариев. Этот небольшой набор не доказывает, что 7B лучше понимает любые команды: проверяется ожидаемый результат интеграции, в том числе отказ или вопрос при неполных данных. Более крупная модель включена для дальнейшей пользовательской пробы; предпросмотр и подтверждение обязательны.

Выбор на этом компьютере переключён на 7B без нового кода подключения. Для возврата: выбрать `qwen2.5:3b` на локальной странице и нажать «Применить выбранную модель». Обе модели сохранены. Во время переключения соединение с облачной CRM временно отсутствовало; последующая проверка показала `online: true`, без ошибки. Смена модели сама по себе не исправляет сетевую доступность облака.
